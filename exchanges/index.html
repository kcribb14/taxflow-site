Exchanges and wallets

Bring the files your exchanges already give you.

TaxFlow reads exchange exports on your device. It does not connect to exchanges or ask for API keys. Here is every source it knows, and how well it knows it.

Supported sources

Built-in reader

TaxFlow recognises the file and reads it as it is.

Mapper preset

The column mapper opens with the columns filled in. You check them before importing.

Column mapper

You tell the column mapper which column is which, once, and save it for next time.

Not listed, or not reading properly?

Ask for a built-in reader by opening a public issue with the exchange’s name and the column headings of its export. Never include real rows, amounts or wallet addresses.
