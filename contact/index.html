Contact

Report a problem or request an exchange.

TaxFlow takes problem reports and exchange requests as GitHub issues. Issues are public, so anyone with the same problem can find the answer.

Open a GitHub issue

You need a free GitHub account to open an issue. There is no email support.

Reporting a problem

Say which screen you were on, what you did, what you expected and what happened instead. Add your browser and device, and a screenshot if it helps, with figures hidden.

Requesting an exchange

Name the exchange and the export you downloaded, and paste only the first line of the file: the column headings. That is usually enough to build a reader.

A figure looks wrong

Describe the transaction in made-up numbers that still show the problem, for example a buy of 1 coin at $100 and a sale at $150, and the figure you expected.

Privacy

Never post your real data.

GitHub issues are public and permanent. A made-up example is enough to fix almost any problem.

  • No real transaction rows, amounts or balances.
  • No wallet addresses, transaction hashes or account numbers.
  • No names, email addresses or tax file numbers.
  • No project backup files: they contain your raw exchange files.

Note

Before you report, check the help centre. Many questions about a particular exchange are answered in its guide.
