Class Super export

Prepare your fund's crypto for Class Super's Excel Transaction Loader: the Portfolio and Market Price tabs, the fund code, and the follow-up checklist.

Updated 17 October 2026

Follow along in the app. Your files stay on your device.

Open the app

Class Super does not take a crypto file directly. Its route for backfilling transactions is the Excel Transaction Loader, a Windows Excel workbook with macros, which you fill in and submit with an upload code. TaxFlow produces paste-ready copies of the two tabs that matter, plus a checklist of what to do by hand afterwards.

Check

these are spreadsheet copies to paste as values. Some strings Class uses (such as the event type for a disposal) are unconfirmed. Test in a non-production fund if you can, or have the fund's administrator check the first load.

Before you start

  • The project's Taxpayer is SMSF in Settings.
  • Review is clear for the year: the transaction files refuse to build while there is a missing AUD value.
  • In Class, each crypto coin is set up as an unlisted security (an "Investment Account" holding, which Class recommends) or a custom holding account. The holding codes in the loader must match the codes you set up.
  • You know the fund's Class fund code.

Download the files

On Reports, in SMSF files, enter the Class fund code (Class asks for it on every row; TaxFlow saves it with the project). Then download:

File Goes into
class-portfolio.csv The loader's Portfolio tab
class-market-prices.csv The loader's Market Price tab (30 June prices)
class-checklist.txt Your to-do list after loading
rounding-residual-class.csv Units lost to Class's 4 decimal places, per coin

Fill in the loader

  1. Download the loader from Class (Business Level, Transactions, Excel Transaction Loader) on a Windows computer with macros enabled. The loader does not work on a Mac.
  2. Open class-portfolio.csv, copy the rows (not the header), and paste as values into the Portfolio tab in the same column order. Do not insert, delete or move cells in the loader.
  3. Do the same with class-market-prices.csv into the Market Price tab.
  4. Generate an Upload Code in Class and submit.

What the rows contain

  • Buys are Unlisted Security Acquisition rows: net amount = cost base including fees, total brokerage = the fee.
  • Sells are disposal rows at proceeds less fees, with the fee as brokerage.
  • Swaps are a disposal of the coin given up plus an acquisition of the coin received, both at market value.
  • Income (staking, interest) is written as an acquisition of the units at their value, and the checklist tells you to record the matching General Taxable Income amount in Class by hand. TaxFlow does not push staking through the Income tab, because that tab is for distributions and the tax label would differ.
  • Transfers between the fund's own wallets are left out.
  • Holding codes are the coin's code (for example BTC); each row gets a transaction id TF-0001, TF-0002 and so on; units are rounded to 4 decimal places and dollars to 2, Class's limits.

Market prices are written with price type Sell and continuing price true. Both are unconfirmed settings; change them in the loader if your administrator uses others.

After loading

Work through class-checklist.txt: record each income amount and match it, check holdings against TaxFlow's Holdings at 30 June, and look at the rounding residual for coins with tiny balances. Opening balances (coins held before the year) are not included.

Data feeds

Class has a crypto data feed from at least one exchange, which at the time of writing carries cash transactions only. If the fund has a feed, check with the administrator before loading trades that the feed might also bring in.
