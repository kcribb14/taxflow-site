Back up and move your data between devices

Your project lives only in this browser. Export it to a .taxflow.json file to keep a backup or open it on another computer.

Updated 17 October 2026

On this page

  1. Make a backup
  2. Restore or move to another device
  3. More than one project
  4. Moving to a new financial year
  5. Saved column mappings

Follow along in the app. Your files stay on your device.

Open the app

TaxFlow has no accounts and no server, so there is no cloud copy of your work. Your project is saved in this browser's storage on this device, automatically, every time you change something (the footer says "Saved on this device"). That is private, but it also means:

  • Another browser, another computer or a private window will not see your project.
  • Clearing your browser's site data deletes it.
  • If the browser refuses to save (some private modes do), the app shows a banner saying your work stays in this tab only.

A backup file solves all three.

Make a backup

  1. Open Settings.
  2. Under Your project, choose Export project. Your browser downloads a .taxflow.json file named after the project.
  3. Store it somewhere private: an encrypted drive, a password manager's file storage, or a folder only you can open.

Do this after any session where you made fixes in Review, and once more when you have finished a year.

Check

the backup contains your raw exchange files (every row, including wallet addresses and transaction hashes), all your fixes and settings, saved column mappings, and any CoinGecko key you entered. Treat it like a bank statement. Do not email it to yourself unencrypted or post it anywhere public.

Restore or move to another device

  1. Copy the .taxflow.json file to the other device.
  2. Open the app there, go to Settings, and choose Import project file.
  3. If that browser already has a project, the app asks before replacing it. Export that one first if you want to keep it.

TaxFlow checks the file's shape and version before opening it. A damaged or edited file is refused with a message saying what is wrong, rather than half-loaded. Projects saved by older versions of TaxFlow open with today's defaults for any setting that did not exist then.

More than one project

You can keep several projects in one browser, for example your own return, your SMSF and the sample portfolio. Use the project menu in the app's header to create, rename, duplicate, switch between or delete projects. Each project has its own files, fixes and settings, and its own backup file. Keep an SMSF in a separate project from your personal return: they are different taxpayers and the settings (entity, discount, exports) differ.

Moving to a new financial year

You do not need a new project each year. Add the new year's exports to the same project and TaxFlow works out every year from the start of your history, carrying losses and parcels forward. Remove nothing: earlier years are what make this year's cost bases right.

If you download a fresh "all time" export that overlaps files you already added, replace the old file with the new one (use Replace on the file in Import) rather than adding both. TaxFlow refuses a file whose contents are identical to one already in the project, but two different exports that overlap in time would count the overlapping trades twice.

Saved column mappings

Mappings you build in the column mapper travel inside the project backup. You can also export a single mapping as JSON from Import. A mapping holds column headers and rules only, never transaction rows.
