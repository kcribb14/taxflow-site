Back up and move your data between devices

Your project lives only in this browser. Export it to a .taxflow.json file to keep a backup or open it on another computer.

Updated 18 October 2026

On this page

  4. More than one project
  5. Moving to a new financial year
  6. Saved column mappings

Follow along in the app. Your files stay on your device.

Open the app

TaxFlow has no accounts and no server, so there is no cloud copy of your work. Your project is saved in this browser's storage on this device, automatically, every time you change something (the footer says "Saved on this device"). That is private, but it also means:

  • Another browser, another computer or a private window will not see your project. A different app address or port also has separate browser storage.
  • Clearing your browser's site data deletes it.
  • If the browser refuses to save (some private modes do), the app shows a banner saying your work stays in this tab only.

A backup is a separate portable copy. Keep one even when the footer says Saved: browser storage can be cleared or removed under storage pressure. Reuse the same trusted app address when returning to your work; restore a backup if you move to a different address.

Make a backup

  1. Open Settings and find Back up and restore.
  2. Choose Download backup for a readable .taxflow.json file, or Private backup for a password-encrypted copy. The private-backup password is separate from any browser-vault password or recovery key. Keep that password safe: TaxFlow cannot reset it.
  3. Store it somewhere private: an encrypted drive, a password manager's file storage, or a folder only you can open.

Do this after any session where you made fixes in Review, and once more when you have finished a year.

Check

the backup contains raw exchange files (including wallet addresses and transaction hashes), fixes, settings, saved mappings and recovery records. New backups omit provider API keys; your CoinGecko key is stored separately in that browser. Readable backups expose their contents to anyone with the file. Treat them like a bank statement.

If downloads are blocked, use Copy backup text and save the whole text in a private file. The fallback text for a Private backup remains encrypted. Test a restore before depending on a backup.

Restore or move to another device

  1. Copy the .taxflow.json file to the other device.
  2. Open the app there, go to Settings, and choose Import project file.
  3. Enter the backup’s own password if it is encrypted. TaxFlow opens a restored copy as a new project; your current project is kept. Select between them using the project menu.

Set up online-price provider credentials again on the new device if needed. Some legacy project files contain a key: the restore notice tells you whether it was adopted or an existing browser key was kept. New backups do not include it.

TaxFlow checks the file's shape and version before opening it. A damaged or edited file is refused with a message saying what is wrong, rather than half-loaded. Projects saved by older versions of TaxFlow open with today's defaults for any setting that did not exist then.

If another tab changed your work

Use one editing tab at a time for this browser workspace. Other tabs can view their snapshots, but a stale tab cannot save over newer work. If TaxFlow reports a conflict, save that tab’s draft as a readable or Private backup first, then explicitly reload the saved version. Restore a draft backup as a separate project if you need to compare it. TaxFlow does not silently merge financial edits between tabs.

More than one project

You can keep several projects in one browser, for example your own return, your SMSF and the sample portfolio. Use the project menu in the app's header to create, rename, duplicate, switch between or delete projects. Each project has its own files, fixes and settings, and its own backup file. Keep an SMSF in a separate project from your personal return: they are different taxpayers and the settings (entity, discount, exports) differ.

Moving to a new financial year

You do not need a new project each year. Add the new year's exports to the same project and TaxFlow works out every year from the start of your history, carrying losses and parcels forward. Remove nothing: earlier years are what make this year's cost bases right.

If you download a fresh "all time" export that overlaps files you already added, replace the old file with the new one (use Replace on the file in Import) rather than adding both. TaxFlow warns about identical contents and requires a deliberate Add action; do not add the same records twice. Two different exports that overlap in time can also count overlapping trades twice.

Saved column mappings

Mappings you build in the column mapper travel inside the project backup. You can also export a single mapping as JSON from Import. A mapping holds column headers and rules only, never transaction rows.
