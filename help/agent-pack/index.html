The tax agent pack for your accountant

What is in TaxFlow's tax agent pack (.zip), what each file is for, and how to hand it to your accountant or keep it as your records.

Updated 17 October 2026

Open the app

If a registered tax agent prepares your return, the tax agent pack gives them everything in one zip: the return figures, every disposal parcel by parcel, your income, what you still hold, and a record of every transaction with the file and line it came from. It is also a good set of records for you to keep, whether or not you use an agent.

How to download it

  1. Open Reports and pick the tax year at the top.
  2. Clear Review first if you can. The pack works with open items, but the figures then contain placeholders, and the checks say so.
  3. Under Downloads, choose Download tax agent pack. Or download any single file.

If your browser blocks downloads (some embedded or sandboxed pages do), use View text on each file and copy it.

What is in the zip

File What it is Who uses it
summary.csv Every return figure (item 18 labels, CGT schedule, other income), the checks and the assumptions, in two columns Your agent, first
disposals.csv One row per parcel per disposal: dates acquired and disposed, asset, quantity, proceeds, cost base, gain or loss, whether held 12 months, discount fraction, category, wallet, event id and source file and line Your agent; the ATO if asked
income.csv Each income receipt in the year, with value and type Your agent
holdings.csv What you hold after the last transaction, with cost base and category Next year's return; your planning
records.csv Every transaction across all years, for ATO record keeping, with the value source and a "keep until" date You, for five years
myob-cgt-worksheet.csv One row per disposal in the column order MYOB and LodgeiT use for a CGT worksheet Agents on MYOB or LodgeiT
handitax-cgt.csv Per-asset summary rows (category code O, discount flag) Agents on HandiTax
trading.csv The trading-stock working for each year (header only for an investor) Traders' agents
forex.csv Foreign currency disposals and their gains or losses If you held foreign currency
sbr.json The return figures keyed by public SBR element ids, for agent software. Not for lodgment. Agent software
README.txt What each file is, plus your assumptions Everyone

CSV files use commas, Windows line ends and AUD to the cent. Dates are local YYYY-MM-DD in your project's time zone.

What your agent will look for

  • The assumptions. Parcel method, investor or trader, residency, time zone, airdrop treatment and carried-in losses are all in summary.csv and the README. A different method or treatment can change the answer, so make sure they match what your agent expects.
  • Open items. If YEAR_COMPLETE is false, tell your agent what is still open and why, for example a $0 cost base you accepted because the purchase records are gone.
  • The audit trail. Every disposal row names its source file and line. Keep your original exchange exports with the pack so each figure can be traced back.

Sending it

The pack contains your full transaction history, including wallet addresses. Send it the way your agent prefers for confidential documents (most firms have a secure portal) rather than as a plain email attachment.

SMSF and business extras

  • SMSF trustees get separate BGL and Class files on the same screen. See SMSF overview.
  • GST-registered businesses get BAS labels and a worksheet on BAS. See BAS and GST for crypto.

Keeping records

records.csv gives each transaction a "keep until" date five years after that transaction. It is an earliest reminder, not permission to delete purchase records: an asset still held needs its purchase evidence, and disposal or carried-forward losses can require longer retention. Store the pack with original exports and a project backup. Follow the current ATO guidance linked in Record keeping.
