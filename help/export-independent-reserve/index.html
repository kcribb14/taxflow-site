Export your Independent Reserve history

Independent Reserve has no built-in importer yet. Download the Transaction History CSV per currency and map it with the preset.

Independent Reserve has not published the column layout of its CSV exports, and TaxFlow has not yet seen a real file to pin it down. So instead of a built-in importer that might misread your file, TaxFlow uses the column mapper with an Independent Reserve preset as a starting point. You confirm each column against your own file before anything is imported.

What to download

Independent Reserve offers two exports:

  • Transaction History (one file per currency account: AUD, BTC, ETH and so on). This is a ledger: deposits, withdrawals, trades, brokerage and GST appear as separate rows. Use this one.
  • Order Statement (your orders). Some tax tools take trades from this file. It does not show deposits and withdrawals.

How to get the Transaction History

  1. Sign in to Independent Reserve on the web.
  2. Go to Transactions, then Transaction history.
  3. Select the download icon and choose Download transaction history as a CSV.
  4. Leave Rollup trades unticked, so each trade keeps its own rows.
  5. Choose the full date range.
  6. Repeat for each currency account you have used, including AUD.

These steps come from public guides and have not been checked against a live account, so the labels may differ slightly.

Map it in TaxFlow

  1. Open Import and drop in the files. TaxFlow does not recognise them automatically; choose Independent Reserve as the exchange, then Map columns.
  2. In the mapper, Start from a preset and choose the Independent Reserve preset (marked [U] for unconfirmed).
  3. Go through each step and check the preset against your file's real headers:
    • Row shape: Ledger (one asset movement per row).
    • Columns: date CreatedTimestampUtc, asset CurrencyCode, credit Credit, debit Debit, type Type, and group CorrelationId (which ties a trade's rows together).
    • Transaction types: Trade as trade; Brokerage, GST, DepositFee, WithdrawalFee, AccountFee, StatementFee as fee; Deposit and Withdrawal as deposit and withdrawal; ReferralCommission as other income.
    • Dates: the preset expects ISO 8601 times in UTC. Check a few against your account.
  4. Read the Dry run: counts per type, balances per asset, and any negative balances. A negative balance usually means a currency file is missing or a type is mapped the wrong way.
  5. Name the mapping and Save mapping and import. Next year, TaxFlow offers your saved mapping automatically for files with the same header.

If a column in the preset is not in your file, the mapper shows it as not mapped and asks you to pick the right one. If your file's headers are quite different, ignore the preset and map from scratch.

Gotchas

  • Bitcoin is Xbt. Independent Reserve writes currency codes like Xbt, Aud and Usd. The mapper reads XBT as BTC.
  • Brokerage and GST are separate rows. Mapping them as fees, grouped with the trade by CorrelationId, adds them to the cost of the trade. If they are left unmapped they are listed as unsupported, and your cost bases will be too low.
  • Timestamps. If you have both a created and a settled timestamp, use the created one for the date unless your accountant says otherwise, and use the same choice every year.
  • One currency per file. Add every currency's file under the same wallet name, Independent Reserve, so trades between AUD and a coin line up.

Help us add a built-in importer

If you are willing, send us the header row only (the first line, no transaction rows) of each file through the contact page on this website. A confirmed header is all we need to build a proper importer.
